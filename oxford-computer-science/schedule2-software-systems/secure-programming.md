 ## Summary

 Many security vulnerabilities arise at the programming level. These can often be attributed to inadequate handling of exceptional situations, poor understanding of the details of the programming language in use, incomplete descriptions of the interface between components,  and insufficient care in the treatment of concurrency and threading issues. Moreover, there is often a mismatch between high-level security requirements and the corresponding code-level requirements.

This course addresses those problems from a programming perspective in a security context, with the aim of improving the practitioner's ability in designing, writing, and reviewing security-critical code.
