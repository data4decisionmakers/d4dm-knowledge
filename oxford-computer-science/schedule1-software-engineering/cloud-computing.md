 ## Summary

 Cloud computing now powers a huge range of our daily activities, from online video to our transport networks and financial services. As the use of cloud has grown the services offered by cloud providers has also grown from the basic building blocks to the full stack of software delivery components.Yet as public cloud matures, we see challenges to its dominance. Companies have concerns about the cost of the cloud services and regulators and governments worry about vendor lock in and concentration risk.This course covers the changing landscape of public cloud evolution and how software development and architectures have evolved as public cloud has matured. We will explore how infrastructure as code allows application architectures to evolve over time and in response to changing business requirements.
